Set up the arcade Mac

Hotel Paradiso Arcade is a full-screen menu of Hotel Paradiso, Sacra Pasta and Do Not Disturb, played with just the mouse. These steps give it its own user account on the Mac, open it by itself at login, and stop that account from running anything else or visiting websites. Your own account stays exactly as it is. It takes about 15 minutes. You need macOS 10.15 Catalina or later and an administrator account.

1. Install the app (in your own account)

  1. Drag Hotel Paradiso Arcade from this disk image into Applications.
  2. The app isn't from the App Store or signed by a registered developer, so macOS would block it. Open Terminal (Applications > Utilities), paste this line and press Return: 
    xattr -dr com.apple.quarantine "/Applications/Hotel Paradiso Arcade.app"
  3. Open the app from Applications and try each game. To leave the arcade, press Control Option Command Q and type the exit code, paradiso.

2. Make the Arcade account

  1. System Preferences > Users & Groups. Click the lock, then +.
  2. New Account: Standard. Full name Arcade, account name arcade. Give it a password (you'll need it for step 3).
  3. Click Login Options and set Automatic login to Arcade, so the Mac goes straight into the arcade when it's switched on. (If FileVault is on, macOS won't allow automatic login; you'd type the Arcade password at start-up instead.)
  4. Copy Hotel Paradiso Arcade.mobileconfig from this disk image into the Shared folder (/Users/Shared) so the Arcade account can reach it.

3. Set up the Arcade account

Do these in order. The profile in the last step blocks System Preferences and Terminal for this account, so anything else has to happen before it.

  1. Log out, and log in as Arcade. Skip the Apple ID and Siri questions.
  2. Choose your own exit code (recommended, since paradiso is printed in this guide). In Terminal, with your code in place of mysecret: 
    mkdir -p ~/Library/Application\ Support/Hotel\ Paradiso\ Arcade
echo 'mysecret' > ~/Library/Application\ Support/Hotel\ Paradiso\ Arcade/exit-code.txt
  3. System Preferences > Energy Saver: set the display and computer never to sleep (or as long as you like). Desktop & Screen Saver: screen saver to Never.
  4. System Preferences > Keyboard > Shortcuts > Spotlight: untick both shortcuts.
  5. Open /Users/Shared in Finder and double-click Hotel Paradiso Arcade.mobileconfig. System Preferences opens on Profiles: click Install, then Install again, and type your administrator name and password when asked.
  6. Log out and log back in as Arcade. The arcade should fill the screen by itself.

4. Check it's locked down

  • The arcade opens at login, with no Dock or menu bar.
  • Each game starts, and quitting it (the game's own Quit, or Command Q) brings the menu back. So does holding the right mouse button down for three seconds during a game.
  • While a game is running, try Command Tab to Finder and open Safari or Terminal from Applications: macOS should refuse ("You don't have permission to use the application").

The profile hasn't been tried on a real Catalina Mac yet. If the last check doesn't hold (Safari still opens), use Screen Time instead, from the Arcade account before installing the profile: Screen Time > Options: turn it on and Use Screen Time Passcode; Downtime: Every Day, 12:00 AM to 11:59 PM, with Block at downtime; Always Allowed: tick only Hotel Paradiso Arcade; Content & Privacy > Content: Allowed Websites Only, with the list emptied.

Getting out, updating, removing

  • To use the Mac yourself: Control Option Command Q, the exit code, then Shift Command Q to log out, and log in as yourself.
  • To update the games: from your own account, replace the app in Applications with the one from a newer disk image, and run the xattr line from step 1 again.
  • To undo it all: from your own account, in Terminal: 
    sudo profiles -R -p io.github.swartzcr.hotelparadiso.arcade.profile.main -U arcade
    then delete the Arcade account in Users & Groups.

Worth knowing

  • Saved games are kept for the Arcade account, so they're shared by everyone who plays.
  • Someone who knows Macs well could still get past this with the power button and a restart into recovery mode. On an Intel Mac you can stop that with a firmware password: restart holding Command R, then Utilities > Startup Security Utility (or Firmware Password Utility).
